FilesMate プレビュー版

Windows 11 22H2（ビルド 22621）以降の x64 環境が必要です。このインストーラーは Windows 10 と ARM64 に対応していません。

.NET と Windows App SDK のランタイムを同梱しています。通常は現在のユーザーの %LOCALAPPDATA%\Programs\FilesMate にインストールします。既定のファイルマネージャーを自動で変更することはありません。

初回の案内でインデックス、グローバル検索、自動起動、お気に入り、アルファベットナビゲーション、外観を選択できます。初期設定では利用可能なローカルドライブを 6 階層まで登録します。更新時は既存の対象範囲と階層設定を保持します。

グローバル検索は、有効にすると別のプロセスとして常駐します。既定では Alt+Space で表示、Esc で閉じる、Enter で項目を開く、Ctrl+Enter で保存場所を開きます。「設定 > 検索」でショートカット、常駐、自動起動を変更できます。終了するにはトレイのメニューを使います。ショートカットが使用中の場合は別の組み合わせを選択してください。

お気に入りはファイルやフォルダーの場所を保存します。追加や削除によって元のファイルをコピー・削除することはありません。お気に入りバーのメニューからグループを整理できます。

「設定 > 全般 > 表示言語」で英語、日本語、簡体字中国語、Windows の言語を選択できます。変更すると、ファイル転送の完了後に FilesMate と起動中のバックグラウンド検索が自動的に再起動し、タブが復元されます。日付と数値には Windows の地域設定を使用します。Windows のダイアログや Office/WPS のプレビューは、それぞれの言語設定に従う場合があります。

一部のプレビュー形式には Windows のコーデックやプレビューハンドラーが必要です。ファイルをダブルクリックすると既定のアプリで開きます。任意の Flow Launcher 連携は、このインストーラーでは設定しません。

アンインストールは Windows の「設定 > アプリ > インストールされているアプリ」から行います。ユーザー設定は保持します。このインストール先が所有しているフォルダーの関連付けは復元します。

これはテストとフィードバック用のプレビュー版です。問題を報告する際は Windows のバージョンと再現手順を記載してください。個人のファイル内容、署名用の秘密鍵、個人プロファイルのデータは添付しないでください。
