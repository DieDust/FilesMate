FilesMate Preview

Requires Windows 11 22H2 (build 22621) or later, x64. This installer does not support Windows 10 or ARM64.

The .NET and Windows App SDK runtimes are included. Installation is per user, normally in %LOCALAPPDATA%\Programs\FilesMate. Your default file manager is not changed automatically.

The first-run guide lets you choose indexing, global search, sign-in startup, favorites, alphabet navigation, and appearance. Initial indexing includes available local drives with a default depth of 6. Existing scope and depth settings are preserved during upgrades.

Global search runs as a separate process when enabled. Alt+Space opens search by default; Esc hides it; Enter opens a result; Ctrl+Enter opens its location. Change the shortcut, background residency, or sign-in startup in Settings > Search. Use the tray menu to exit background search. If the shortcut is in use, choose a different one.

Favorites store references to files and folders; adding or removing favorites does not copy or delete the original files. Organize groups from the favorites bar menu.

Settings > General > Display language offers English, Japanese, Simplified Chinese, and Windows language. Changing the language automatically restarts FilesMate and running background search after file transfers finish, then restores open tabs. Dates and numbers retain the Windows regional format. Windows dialogs and third-party Office/WPS previews may use their own language settings.

Some preview formats require installed Windows codecs or preview handlers. Double-clicking a file uses its default application. The optional Flow Launcher integration is not configured by this installer.

Uninstall from Windows Settings > Apps > Installed apps. User settings are retained. Folder associations still owned by this installation are restored.

This is a preview for testing and feedback. When reporting issues, include your Windows version and steps to reproduce. Do not attach private file contents, signing keys, or personal profile data.
