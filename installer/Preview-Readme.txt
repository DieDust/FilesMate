FilesMate 试用版

系统要求：Windows 11 22H2（系统版本 22621）或更新版本，x64 处理器。
此安装包不支持 Windows 10 和 ARM64。

安装包已包含 .NET 和 Windows App SDK 运行组件，无需安装开发环境。
安装仅对当前用户生效，默认路径为 %LOCALAPPDATA%\Programs\FilesMate。
安装不会自动替换系统资源管理器。首次打开新版时，可选择索引、全局搜索、开机启动与收藏栏。

全局搜索：在首次指引中启用后，在后台保留一个独立的轻量搜索进程。
按 Alt+Space 呼出搜索框；Esc 收起；Enter 打开结果；Ctrl+Enter 定位文件。
可以在“设置 > 搜索”或搜索框的齿轮按钮中修改快捷键、关闭后台驻留。
也可以在搜索设置中关闭开机启动。
托盘菜单提供退出入口。首次使用若快捷键被其他启动器占用，请关闭该启动器
或更换快捷键。全局搜索覆盖已有索引位置，可在文件管理器“设置 > 搜索”
中选择磁盘并更新索引。本版不安装第三方插件。
首次使用默认选择全部可用的本地硬盘及移动磁盘，默认扫描深度仍为 6 层。
升级会保留已有用户保存的磁盘范围和扫描深度。

收藏栏：在地址栏下方收藏文件和文件夹，支持分组下拉、拖入添加、拖动排序。
可通过文件右键“添加到收藏栏”选择分组，在收藏栏菜单中整理、重命名和移除。
收藏只保存原文件位置，不复制文件。在“设置 > 文件和文件夹”中可随时显示/隐藏，或重新打开功能指引。

图片和视频缩略图可使用 Windows 提供的缩略图能力，不要求安装
VividPlayer 或果核看图。少数格式需要系统支持相应解码器或缩略图提供程序。
双击文件使用用户设置的默认打开方式。
Flow Launcher 联动插件是独立可选组件，本安装包不更改 Flow Launcher 设置。

文件管理器窗口兼容原版 SnowShot 的“固定选中文件到屏幕”功能。
需要 SnowShot 提供此入口（已验证 1.0.3-beta），在其设置中配置快捷键。
多选拖拽按当前列表顺序展示前三个选中项图标，角标显示全部选中数量。

卸载：在 Windows 设置 > 应用 > 安装的应用中卸载 FilesMate。
卸载会恢复仍指向本安装位置的文件夹打开关联，保留用户设置。

以及方便分享的截图；请勿附带私人文件内容。
